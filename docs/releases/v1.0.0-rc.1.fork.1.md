# PerPay 1.0.0-rc.1.fork.1

本定制源码合入上游至 `17c34dc`，包括账号删除后安全重启与备份恢复、流水分组和分页稳定性、统计刷新失败反馈及后台布局修复。当前未发布定制镜像或创建 Release；源码合并不代表已推送或部署。

## 定制保留

保留按网站向上/向下调整金额，向下从减1分开始，最低应付1分，不增加原价优先逻辑。金额占用、冷却及旧单幂等约束保持原样。精确金额、手机、可滚动二维码弹窗及未确认付款提示继续作为 Fork 定制保留。

## 账号删除与升级

删除未使用账号时标记删除，保留不可变的历史归属，清除当前密钥和可用配置。有活跃网站、订单或流水引用的账号仍不能删除。迁移不会修复此前已经丢失的账号证据，不绕过启动完整性检查。

兼容范围24—39；原有迁移1—38的编号、SQL与校验和不变。上游删除状态迁移38在本 Fork 为39，不能将上游 schema38 与本 Fork schema38 混用。

升级前保留一致性数据库备份与原 `PERPAY_MASTER_KEY` 主密钥，在隔离副本验证迁移、旧订单、密钥和恢复。`app`、`backup`、`maintenance` 必须使用同一份支持 Fork schema39 的构建。旧 `1.0.0-alpha.2.fork.2` 最高支持38，不能直接打开新库，也不能恢复旧库覆盖升级后的新收款。

参见 [Fork 维护说明](https://github.com/Sark1tama/PerPay/blob/main/docs/fork-maintenance.md)、[定制部署指南](https://github.com/Sark1tama/PerPay/blob/main/docs/deployment.md)和[维护与恢复](https://github.com/Sark1tama/PerPay/blob/main/docs/maintenance.md#固定版本与回滚)。
