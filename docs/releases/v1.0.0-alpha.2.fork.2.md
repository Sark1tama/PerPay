# PerPay 1.0.0-alpha.2.fork.2

本定制源码合入上游至 `a932e1e`，增加支付宝多账号、网站指定／随机／加权分配、后台手动查账、更新检查通道和可选初始化令牌。当前未发布定制镜像或创建 Release；源码合并不代表已经推送或部署。

## 定制保留

按网站向上/向下调整金额，向下从减1分开始，最低应付1分，不增加原价优先逻辑。同账号共享金额占用和冷却，不同账号隔离；旧单重试保留原账号、金额和二维码。向下减价至少保留到官方提供等价能力后再评估替换。

精确金额、禁止四舍五入、手机、放大二维码弹窗及未确认付款提示永久作为 Fork 定制保留。提示不等于付款确认，“24小时内退回”文案不代表系统具备自动退款能力。

## 数据升级

兼容范围24—38；原有迁移1—37的编号、SQL与校验和不变。上游多账号迁移37在本 Fork 为38，保留既有1分金额记录；旧配置迁为默认账号，网站保持原金额方向及策略。

升级前保留一致性数据库备份与原 `PERPAY_MASTER_KEY` 主密钥，在隔离副本验证迁移、密钥、旧订单和备份恢复。`app`、`backup`、`maintenance` 使用同一份已验证的定制镜像；不得直接使用上游镜像或旧 `fork.1` 打开升级后的数据库，不得恢复旧库覆盖新收款。

参见 [Fork 维护说明](https://github.com/Sark1tama/PerPay/blob/main/docs/fork-maintenance.md)、[定制部署指南](https://github.com/Sark1tama/PerPay/blob/main/docs/deployment.md)和[维护与恢复](https://github.com/Sark1tama/PerPay/blob/main/docs/maintenance.md#固定版本与回滚)。
