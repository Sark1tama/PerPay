# PerPay 1.0.0-alpha.2.fork.1

本定制版本合入上游至 `b944672`，保留按网站向上/向下调整应付金额，以及桌面、手机和二维码弹窗的精确金额提醒。当前未发布镜像或创建 Release；源码合并不代表生产环境已升级。

## 主要更新

- 增加复制应付金额和付款后的查账提示，保留禁止四舍五入、手机醒目提示及二维码弹窗滚动。
- 合入固定快照在线备份、损坏主库显式隔离恢复、一次性初始化令牌、通知重试和查账追赶期间的收款准入修复。
- 保留既有迁移1—37的编号、SQL与校验和，并冻结定制版本的数据库兼容上限。

## 升级与恢复

数据库兼容范围为24—37；迁移36为金额方向，37为会话信息，本次不新增迁移。上游同名基础版本只支持到36且迁移内容不同，不能用上游镜像替换本 Fork。

升级前备份数据库并单独保存原 `PERPAY_MASTER_KEY`，在隔离副本验证兼容性。生产部署须另获明确同意，`app`、`backup`、`maintenance` 必须使用同一份经过验证的定制镜像。旧版本能否回退取决于其迁移清单和兼容范围，不能只比较版本字符串，也不能恢复旧备份覆盖升级后新增的收款。
